电信用户行为分析系统 —— 离线演示包
====================================

一、怎么打开
------------
1. 把压缩包完整解压到一个文件夹（不要在压缩包里直接双击）。
2. 双击「启动.bat」。
3. 稍等一两秒，浏览器会自动打开 http://localhost:8088/。
   如果浏览器没有自动打开，手动把上面这个地址复制到浏览器地址栏。
4. 弹出黑色的 PowerShell 窗口是正常的，**它必须保持打开**；
   关掉窗口，网页就断了。看完后直接关掉它即可。

电脑不需要安装 Node.js、Python、MySQL、Docker，也不需要联网。
Windows 10 / 11 自带的 PowerShell 就够用。

如果 8088 端口被别的程序占用，脚本会自动换到 8089–8098 中的空闲端口，
以黑色窗口里打印的地址为准。

二、演示账号（口令都是 123456）
-------------------------------
  13800001234   电信用户：首页、话费、账单、余量、套餐办理、报障、个人信息
  analyst       运营分析员：实时大屏、离线数据分析、系统运行分析
  admin         系统管理员：用户管理、套餐配置、工单管理

登录页下方也列出了这三个账号，可以直接点选。

三、能看到什么
--------------
- 营业厅：游客首页（套餐 / 优惠活动）、登录、6 个用户自助页面
- 数据分析大屏：实时链路、离线链路、系统运行分析三个页面
- 管理后台：账号增删改查、套餐增删改查、工单流转
- 地图、趋势图、漏斗、留存、死信列表等图表全部可用

四、数据说明（请老师知悉）
--------------------------
1. 这是 **离线演示模式**，所有数据来自内置的演示数据集，
   不连接任何后端、数据库或消息队列。
2. 账期固定在 2026-09，数据是那一期的快照，不会随时间变化。
3. 大屏「实时」板块的数字由前端定时器模拟，会动，但不来自真实链路
   （真实的 Kafka → Flink 链路需要虚拟机环境，不在本包范围内）。
4. 管理后台的增、删、改只修改浏览器内存，**刷新页面即还原**，
   这是演示版的预期行为，不是故障。
5. 登录是本地校验，不走网络；清空浏览器数据后重新登录即可。

五、打不开怎么办
----------------
1. 确认解压后的目录里有 dist 文件夹，且 dist/index.html 存在。
2. 手动在浏览器打开黑色窗口里打印的地址（默认 http://localhost:8088/）。
3. 若提示脚本被禁止运行：右键「启动.bat」→ 以管理员身份运行；
   或在该目录打开 PowerShell，执行：
   powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1
4. 换一个浏览器（Chrome / Edge 均可）。
